# Linux System Information Script

A menu-driven Bash script that displays basic system information from the terminal.

## Features
- Show current user and hostname
- Show current date
- Show current shell
- Check whether a directory exists and display its permissions
- Show memory and disk usage
- Count files in the current directory
- Show Linux distribution details
- Input validation (rejects blank input)

## Commands used
`whoami`, `hostname`, `date`, `free`, `df`, `ls`, `find`, `wc`, `/etc/os-release`

## How to run
```bash
chmod +x system_info.sh
./system_info.sh
```
